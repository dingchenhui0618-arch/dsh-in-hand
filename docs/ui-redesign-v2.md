# 掌上 DSH UI redesign v2

这份独立副本把 DSH 的桌面工作台语义压缩成手机单列界面，参考 [DeepSeek Harness 官网](https://deepseek.com/en/harness/) 中的会话、工作区、模型和任务轨迹结构。

## 视觉方向

- **工作台优先**：顶部只保留会话标题、会话入口、新建、主题；实验功能进入会话抽屉，避免牌桌动作抢主导航注意力。
- **上下文可见**：工作区和模型使用一枚轻量胶囊显示在标题下方，点击后打开模型选择抽屉。
- **状态一眼可读**：任务状态收成一条胶囊状态条；待处理状态明确写成“待桌面处理”，避免手机端暗示可以直接批准。
- **内容优先**：token、步骤、缓存命中等统计仍由代码计算，但默认隐藏，任务详情抽屉保留完整信息。
- **对话即轨迹**：助手回复保持无气泡的阅读流，工具调用以折叠步骤组呈现，失败步骤仍然显眼。

## 交互结构

1. 点击左上角“对话”打开带搜索的会话抽屉，按“运行中 / 最近”分组。
2. 点击标题下的工作区/模型胶囊打开模型选择。
3. 点击状态条查看任务、子代理和待处理项。
4. 点击右上角“+”先选择工作区，再创建新会话。
5. 抽屉支持关闭按钮、点背景关闭、Escape 关闭和焦点回收。
