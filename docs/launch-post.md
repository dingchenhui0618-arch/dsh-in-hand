# 把电脑上的 DSH 搬到手机：一周用下来的三个变化

周三傍晚在地铁上，我突然想知道家里那台电脑的活干到哪了。出门前我留了个 agent 在改测试，只来得及说一句「跑完告诉我」，然后就锁屏走了。车过两站，心里越来越没底：它是在跑，还是卡在某个等确认的地方？

总不能为了看一眼再跑回家。于是有了 dsh-in-hand：一个装进 DSH 的插件，把电脑上的会话变成一个手机浏览器能打开的网页。电脑这头装插件、起一个中继；手机那头把地址加到主屏幕，输一次六位配对码。之后不用装 App，不用公网 IP，连上就能看、能说话。

用了一周，说三个真实的变化。都是我个人体验，不代表任何人。

**一、地铁上能接手。** 页面顶部那条状态会直接写「有 1 件事待桌面处理」。批准按钮仍然只在电脑上——这一点我没绕过去，也不想假装绕过去了。但大多数时候我需要的不是点那个按钮，而是说一句「先跳过缓存清理，把单测跑完」，它收到就接着干。上周四我站在换乘通道里把这句话发出去，到家时测试已经绿了。整个过程没开电脑，也没装任何东西。

**二、睡前看进度。** 以前关电脑前得挨个点开会话确认一遍，现在躺床上点开状态条：几个任务在跑、连续的工具卡折成一行「19 个步骤」，哪一步失败会明明白白露出来，不会藏在折叠里。困的时候我不看细节，只看一眼「在跑」和「待处理」的数字，心里有数就睡。

**三、能收 PDF。** 它写完文档导出「改造说明.pdf」，我在手机上直接点开翻了两页，顺手转给了同事。以前这种事只能等回电脑：先找会话，再找文件，再打开。现在文件就在对话里，点一下就行。

不完美的地方也有。项目目录里的截图，在手机上显示不出来——文件路由只服务附件库和 outbox，其他路径一律拒绝，我只能在对话里看到一个路径，点开是原始文件名。问过自己要不要放开，答案是不放：为了几张图把任意路径读取交出去，不划算。这是这一周里唯一一次觉得「要是能再顺手一点就好了」。

技术上能感知到的只有三点：不用公网 IP（电脑在 NAT 后面也能连），不用装 App（浏览器打开、加到主屏幕），换路用的票据 60 秒就过期。别的都在你看不见的地方，我也没打算在 README 里吹。

一周下来我打开了大概十几次，多数是在路上和床上，这个频率只说明我自己用得着。

开源在这，自用为主：https://github.com/dingchenhui0618-arch/dsh-in-hand

怎么装：

```sh
dsh plugin --profile web add dsh-in-hand   # 装插件
dsh web                                    # 重启一次
# 手机打开 http://<电脑的内网 IP>:3099/taskwatch
```
